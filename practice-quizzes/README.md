## How to use

1. Open a quiz, scroll **only as far as the questions**.
2. Answer them on paper / in a note.
3. Scroll to the bottom and compare with the answer key.
4. For each miss, re-read the relevant section of the paired guide.

Roughly 120 questions total across 8 quizzes — about 90 minutes of practice. The mix of MC + SELECT ALL matches the format used in the weekly reading quizzes.
